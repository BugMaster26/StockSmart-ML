# Datos

La aplicación acepta CSV y Excel con, como mínimo, `InvoiceDate`, `StockCode` y `Quantity`; `UnitPrice` se requiere para analizar ingresos. Los nombres equivalentes del dataset Online Retail (por ejemplo `InvoiceDate`, `StockCode`, `Quantity`, `UnitPrice`) se reconocen directamente.

El dataset de UCI no se incluye en el repositorio. Descárguelo desde [UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail) o cárguelo desde la interfaz. Los archivos subidos no se guardan automáticamente.

La aplicación incorpora una demo generada en memoria con etiqueta **DEMOSTRACIÓN (datos sintéticos)**. No representa observaciones reales ni resultados del dataset UCI.
